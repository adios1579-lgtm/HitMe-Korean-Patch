# 너의 눈동자에 히트미 한글패치

PC판 + 호토리 루트 통합 한글패치의 배포 및 자동업데이트 저장소입니다. **원본 게임이 필요한 패치**이며 게임 전체를 제공하지 않습니다.

[최신 설치 패치 받기](https://github.com/adios1579-lgtm/HitMe-Korean-Patch/releases/latest) · [설치/사용 설명](USER_GUIDE.md) · [문제 제보](https://github.com/adios1579-lgtm/HitMe-Korean-Patch/issues)

- 전체 번역 후보 29,178건 및 한글 이미지·UI
- 호토리 루트, 콘솔 오프닝·음악 통합
- 게임 실행 시 업데이트 확인 및 동의 후 적용
- 오프라인 현재 버전 실행, 별도 수동 업데이트, 실패 복구
- 세이브·개인 설정 보존, 폰트 영구 설치 불필요

기존 보류10건은 초벌 수준으로 수용했습니다. 새 자동업데이트 실행기는 합성 파일로 검증했으며, 전체 실게임 전수 검수를 마친 것은 아닙니다. 상세 범위는 릴리스 설명과 시험 기록을 참고하세요.

설치에는 릴리스의 `hitme-korean-patch-버전.zip`을 사용합니다. GitHub가 자동으로 만드는 `Source code` ZIP은 게임 패치가 아닙니다.

업데이트 소스와 배포자 도구는 `src/`, `build_release.py`, `PUBLISHER_GUIDE.md`에 있습니다. 저장소에는 토큰·세이브·원본 게임 아카이브를 넣지 않습니다.
